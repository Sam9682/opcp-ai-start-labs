Anatomy of an AI Agent: the Seven Core Components

Morning · Fundamentals ⏱ ~5 min

Every AI agent, however simple or sophisticated, is built from the same seven building blocks. Understanding each component — and how they connect — lets you reason about any agent you meet or design, including one that operates the opcp-explorer platform.

Learning Objectives

  • Name the seven core components of an AI agent
  • Explain the role each component plays
  • Map the components onto an agent acting on opcp-explorer

The Seven Components

  1. Brain (LLM) — the reasoning engine. It interprets the goal, decides the next step, and chooses which tool to call. Everything else serves the brain or constrains it.
  2. Short-term memory — the working context of the current task: recent steps, intermediate results, and the running scratchpad. It is bounded by the context window.
  3. Long-term memory — persistent knowledge across sessions: past outcomes, learned facts, embeddings in a vector store. It lets the agent recall what happened yesterday.
  4. Tools — the agent's hands. APIs, CLIs, functions, and MCP servers that let it affect the world. On opcp-explorer, tools are the deploy, start, stop, and status operations.
  5. Planner — decomposes a goal into ordered steps and sequences tool calls. It may be an explicit plan or implicit in the brain's step-by-step reasoning.
  6. Execution loop — the engine that repeatedly runs Think → Act → Observe until a stopping condition is met. Covered in depth in the next lesson.
  7. Guardrails — the controls that bound what the agent may do: permissions, limits, approvals, observability, and a kill switch. Covered in depth this afternoon.

How the Components Fit Together

flowchart LR
    Goal[Goal] --> Planner
    Planner --> Brain[Brain / LLM]
    STM[Short-term memory] <--> Brain
    LTM[Long-term memory] <--> Brain
    Brain -->|chooses| Tools
    Tools -->|results| Brain
    Loop[Execution loop] -. drives .-> Brain
    Guardrails -. bound .-> Tools
    Guardrails -. bound .-> Loop

The brain reasons over memory, the planner orders the work, tools act on the world, the loop keeps it turning, and guardrails bound the whole system.

Key Takeaways

  • Seven components: brain, short-term memory, long-term memory, tools, planner, execution loop, guardrails.
  • The brain reasons; memory remembers; tools act; the planner orders; the loop repeats; guardrails bound.
  • Any agent can be analyzed by locating each of these seven parts.
