Anatomie d'un agent IA : les sept composants essentiels

Matin · Fondamentaux ⏱ ~45 min

Tout agent IA, aussi simple ou sophistiqué soit-il, est construit à partir des mêmes sept briques. Comprendre chaque composant — et la façon dont ils se connectent — permet de raisonner sur n'importe quel agent que vous rencontrez ou concevez, y compris un agent qui opère la plateforme opcp-explorer.

Objectifs pédagogiques

  • Nommer les sept composants essentiels d'un agent IA
  • Expliquer le rôle de chaque composant
  • Cartographier les composants sur un agent agissant sur opcp-explorer

Les sept composants

  1. Cerveau (LLM) — le moteur de raisonnement. Il interprète l'objectif, décide de l'étape suivante et choisit l'outil à appeler. Tout le reste sert le cerveau ou le contraint.
  2. Mémoire à court terme — le contexte de travail de la tâche courante : étapes récentes, résultats intermédiaires et bloc-notes en cours. Elle est bornée par la fenêtre de contexte.
  3. Mémoire à long terme — connaissance persistante entre les sessions : résultats passés, faits appris, embeddings dans une base vectorielle. Elle permet à l'agent de se souvenir de ce qui s'est passé hier.
  4. Outils — les mains de l'agent. API, CLI, fonctions et serveurs MCP qui lui permettent d'agir sur le monde. Sur opcp-explorer, les outils sont les opérations de déploiement, démarrage, arrêt et statut.
  5. Planificateur — décompose un objectif en étapes ordonnées et séquence les appels d'outils. Il peut s'agir d'un plan explicite ou implicite dans le raisonnement pas à pas du cerveau.
  6. Boucle d'exécution — le moteur qui exécute en boucle Penser → Agir → Observer jusqu'à ce qu'une condition d'arrêt soit atteinte. Détaillée dans la leçon suivante.
  7. Garde-fous — les contrôles qui bornent ce que l'agent peut faire : permissions, limites, approbations, observabilité et kill switch. Détaillés cet après-midi.

Comment les composants s'articulent

flowchart LR
    Goal[Objectif] --> Planner[Planificateur]
    Planner --> Brain[Cerveau / LLM]
    STM[Mémoire court terme] <--> Brain
    LTM[Mémoire long terme] <--> Brain
    Brain -->|choisit| Tools[Outils]
    Tools -->|résultats| Brain
    Loop[Boucle d'exécution] -. pilote .-> Brain
    Guardrails[Garde-fous] -. borne .-> Tools
    Guardrails -. borne .-> Loop

Le cerveau raisonne sur la mémoire, le planificateur ordonne le travail, les outils agissent sur le monde, la boucle le fait tourner, et les garde-fous bornent l'ensemble.

Points clés à retenir

  • Sept composants : cerveau, mémoire court terme, mémoire long terme, outils, planificateur, boucle d'exécution, garde-fous.
  • Le cerveau raisonne ; la mémoire se souvient ; les outils agissent ; le planificateur ordonne ; la boucle répète ; les garde-fous bornent.
  • Tout agent peut être analysé en localisant chacune de ces sept pièces.
