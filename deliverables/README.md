# Deliverable Templates

Fillable templates for the agentic-AI learning session. Each is provided in
English and French (`.fr.md`).

| Template | Used in | Purpose |
|----------|---------|---------|
| `trace-annotation-worksheet.md` | Morning — trace-reading lab | Annotate the sample execution trace |
| `threat-model-template.md` | Afternoon — threat-modeling workshop | Threat-model an agent; map mitigations to the five guardrail layers |
| `agent-design-template.md` | Afternoon — design capstone | The final, fully documented agent design |

## How to use

1. Copy the relevant template, keeping the headings intact.
2. Replace every _italic prompt_ with your own content.
3. For the threat model and the design doc, complete the five-guardrail-layer
   table — every layer (permissions, operational limits, human approval,
   observability, kill switch) must appear.
4. The workshop and capstone self-assessments check that the required sections
   are present and the five layers are covered.

> **Future enhancement:** an interactive SkillHub form that generates the agent
> design document from guided inputs is planned. For now, these markdown
> templates are the canonical deliverables.
